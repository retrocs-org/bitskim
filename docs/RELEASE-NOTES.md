# BitSkim 0.2

Direct local-network file sharing for macOS, Windows and AmigaOS, with experimental DOS, Atari TOS/MiNTNet, RISC OS and Windows Classic downloads.

- Send files and folder collections, discover nearby computers, or connect by IPv4.
- Conflict policies, transfer queues, rate limits, history and local diagnostics.
- Mac and modern Windows prefer TLS; verified device pairing and checked resume are available. Retro connections are plaintext.
- Apple silicon Mac app and disk image are Developer ID signed, notarized and stapled. Windows downloads are unsigned.
- DOS transfers and discovery have automated checks. RISC OS ARM2 and StrongARM compile/link checked. Atari STinG startup and tools navigation checked; Atari transfers remain unverified.

See `docs/RELEASE-READINESS.md` in the source archive for exact validation and remaining Windows GUI / physical hardware limits. Queues and history are session-only. Maximum individual file size is 2 GiB minus one byte.
