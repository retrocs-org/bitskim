# Regression coverage

The regression suite covers bounded receive filenames, collision suffixes, small destination buffers, transfer-serial binding for asynchronous Mac decisions, queue preservation, OpenSSL certificate naming and Python 3.9 packaging compatibility.

Native Mac decision checks exercise sequential offers so an old decision cannot accept a new transfer. Shared-engine tests use real sockets and address/undefined-behavior sanitizers where available. Release-tool tests cover conflicting tags, changed assets, partial upload recovery and uncommitted inputs.

See [VALIDATION.md](VALIDATION.md) and [RELEASING.md](RELEASING.md) for execution and release procedures.
