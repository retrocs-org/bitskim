# BitSkim icon artwork

The current main icon is a deliberately simple retro mark: a folded file and a broad transfer arrow. Its geometry is drawn directly on a 56×44 pixel grid in `scripts/build-icons.py`. The Amiga and macOS versions use exactly the same geometry, without fine shading or a particle trail.

- `bitskim-amiga-master.png`: native-size four-color master, generated deterministically by the script.
- `bitskim-macos-master.png`: the same pixel mark in Catppuccin Mocha colors on a dark rounded tile. Its enlarged pixels stay crisp.
- `BitSkim.info`: classic DiskObject v1, WBTOOL, two 56×44 two-plane image states and a64KiB stack. Uses Workbench pens0–3, so its colors follow the user's palette. This is a real Amiga icon, not a renamed PNG.
- `BitSkim.icns`: full macOS multiresolution source icon, bundled as BitSkimRetro.icns and referenced by Info.plist. The app loads it directly and explicitly draws the running Dock tile after switching to regular activation policy.
- `BitSkim-menu.png`: monochrome template drawn from the same native mark for the Mac menu bar.
- `bitskim-amiga-preview.png`: enlarged preview using typical gray/black/white/blue Workbench colors.
- Website PNG and favicon are regenerated from the matching Mac design.

The preferences icon remains the existing native pixel-art sliders/control-panel icon, byte-for-byte unchanged by this redesign. `BitSkimPrefs.info` is a WBTOOL with two image states and a64KiB stack. The drawer icon `BitSkimDrawer.info` uses the supplied SoftwarePackage artwork with WBDRAWER/OldDrawerData; install it as `BitSkim.info` beside the application's drawer. `BitSkimPrefs-preview.png` and `BitSkimDrawer-preview.png` show these companions.

The current native pixel design is defined completely by code. No Apple or Amiga logo art is incorporated. Superseded artwork and its production records are kept locally and excluded from release source packages.

Rebuild with Python3 and Pillow: `python3 scripts/build-icons.py`. Classic icon structure and both image states are verified separately from native Workbench visual confirmation.

Windows uses `BitSkim.ico`, generated in sizes 16–256 from the same retro master used by the Mac and Amiga clients.

RISC OS uses `BitSkim-RISCOS.sprites`, a classic 32×32 mode-20 4bpp sprite with a mask, derived deterministically from the committed Amiga pixel master by `scripts/build-riscos-icon.py`. It contains the `!bitskim` icon-bar/Filer sprite and is installed as `!BitSkim/!Sprites`. It approximates the existing identity in the traditional sixteen-colour palette. Native RISC OS rendering has not been verified.

`Install-BitSkim.info` uses the project owner's supplied `Install.info` artwork as a WBPROJECT icon, with StartInstaller as its DefaultTool. `BitSkimDrawer.info` uses the supplied `SoftwarePackage.info` artwork as a WBDRAWER with normal Workbench drawer geometry. Both normal and selected planar image states are preserved byte-for-byte. Originals and archive/file SHA-256 provenance are committed in `generic-amiga-installer/`.

`scripts/amiga_package_icons.py` adapts only metadata, and both icon build entry points use it so later builds retain these supplied icons. The package installs the drawer icon as **BitSkim.info beside the BitSkim directory**, and the installer icon as **BitSkim/Install-BitSkim.info**. The main application and preferences tool icons remain separate. The installer also copies the outer package drawer icon to the chosen parent drawer when it is available.

`BitSkimGuide.info` is original code-drawn classic two-plane book artwork, generated by `scripts/build-amiga-guide.py` (MIT). It is a Workbench project opening the packaged manual in MultiView, with normal and selected images. The generator is the editable master.

Installation templates generated by `scripts/build-amiga-guide.py`: `HelpDrawer.info` reuses the original book artwork as a drawer, `SettingsDrawer.info` reuses the supplied generic drawer artwork, and `BitSkim.prefs.info` reuses the original Preferences artwork as a project opening BitSkimPrefs. The installer adjusts its DefaultTool for the selected Preferences directory. Shared data is deliberately installed without a drawer icon. Templates are kept under InstallAssets/ in the distribution, not installed as shared payload.

The distribution `BitSkimDrawer.info` explicitly sets revision-1 DrawerData2 to `DDFLAGS_SHOWICONS` and `DDVM_BYICON`. Workbench therefore opens the archive drawer in icons-only view even when its parent uses Show All Files. Its original normal/selected artwork is preserved.

`InstallAssets/Startup.info` reuses the main application tool icon for the small BitSkimStart WBStartup launcher; the installer adds DONOTWAIT. It is not a project icon or a copy of the full application binary.

`BitSkim-Windows-Classic.ico` derives from the existing `bitskim-macos-master.png`
using `scripts/build-windows-legacy-icon.py` (Pillow). It contains 16/32/48-pixel,
16-colour DIB images with binary transparency masks, avoiding PNG icon payloads
for the experimental Windows 95/98/Me/XP client.
